# Fly Horizons — Brand Export

**À l'intention du graphiste externe**

Ce dossier contient tout ce qu'il faut pour créer des supports imprimés (flyers, affiches, cartes de visite, roll-ups, brochures) indiscernables des créations originales de Fly Horizons.

---

## Commencer ici

1. **Lisez `brand.md`** — c'est la référence complète : couleurs, typographie, composants, règles d'usage, voix de marque, consignes d'impression
2. **Ouvrez `components.html`** dans un navigateur — c'est le guide interactif de tous les composants visuels du site. Imprimez-le en PDF via le navigateur (Fichier → Imprimer → PDF)
3. **Consultez `colors.json`, `typography.json`, `spacing.json`** pour les valeurs exactes de chaque token

---

## Identité en 5 points

| Point | Règle |
|-------|-------|
| **Police** | Poppins uniquement (Google Fonts, 300–900) |
| **Couleurs** | Navy `#0b2238` + Gold `#F2B705` + Blanc `#ffffff` + Fond `#f5f5f7` |
| **Titres** | Toujours font-black (900), précédés d'une overline gold 10px UPPERCASE |
| **Fond** | `#f5f5f7` standard, `#ffffff` sections, `#0b2238` footer/hero uniquement |
| **CTA** | Fond gold `#F2B705`, texte navy `#0b2238`, font-black, radius 12px |

## Logos — règles d'usage rapides

| Contexte | Fichier à utiliser |
|----------|--------------------|
| Fond clair (blanc, gris) | `fly-horizons-logo-navy.svg` |
| Fond sombre (navy, photo) | `fly-horizons-logo-white.svg` |
| Format PNG uniquement | `logo-fly-horizons-navy.png` ou `logo-fly-horizons-white.png` |
| Favicon / icône app | `icons/icone.svg` |

**Jamais** : déformer le logo, changer ses couleurs, le placer sur fond gold.
