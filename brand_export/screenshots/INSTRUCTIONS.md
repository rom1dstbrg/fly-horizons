# Captures d'écran — Instructions

Les captures haute résolution du site doivent être réalisées directement depuis le site live.

## Outil recommandé

**Browser extension "GoFullPage"** (Chrome/Firefox) pour capturer la page entière en PNG haute résolution.

Ou via DevTools → Ctrl+Shift+P → "Capture full size screenshot"

## Résolution recommandée

- Desktop : viewport 1440px de large, device pixel ratio 2x (Retina)
- Mobile : viewport 390px (iPhone 14), device pixel ratio 3x
